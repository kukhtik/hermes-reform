- `test_memories_dirs_are_different_paths`: Verify `get_hermes_home()/memories` resolves to different paths for each profile

### (d) Subprocess Env Isolation — 6 tests
- `test_hermes_home_set_to_computed_profile_home`: With HERMES_HOME set, subprocess env has it (os.path.normpath for Windows backslash handling)
- `test_hermes_home_falls_back_to_platform_default_when_unset`: Without HERMES_HOME in parent, child gets platform default (correct F0.7 fallback propagation)
- `test_overrides_can_add_hermes_home`: Explicit overrides= can add HERMES_HOME even when parent has none
- `test_overrides_win_over_parent_hermes_home`: overrides= take precedence
- `test_other_env_vars_copied_from_parent`: os.environ is copied (ambient vars present)
- `test_helper_result_is_independent_copy`: Each call returns a fresh dict; mutations don't affect os.environ

### Test Results

| Run | Result | Notes |
|-----|--------|-------|
| RED (initial) | 9/12 passed, 3 failed | Initial tests had wrong expectations for subprocess env behavior on Windows |
| GREEN (corrected) | **12/12 passed** | Tests corrected to match actual F0.7 contract |

### RED Failures Explained
1. `test_hermes_home_not_injected_when_parent_has_none`: WRONG expectation — `get_subprocess_env()` ALWAYS calls `get_hermes_home()` and sets HERMES_HOME, even when the env var is unset in the parent. The fallback is to the platform default. This is the correct F0.7 behavior (profile propagation always happens).
2. `test_hermes_home_injected_when_parent_has_it` / `test_helper_result_is_independent_copy`: Windows path normalization (`C:/` vs `C:\`) — fixed with `os.path.normpath()`.

## Findings

### No Leaks Found
All per-profile paths are correctly isolated. No cross-profile data leakage was discovered.

### Key Design Points
1. **`get_hermes_home()` is the single source of truth** for all profile-scoped paths
2. **`get_subprocess_env()` is the canonical subprocess spawn helper** — always sets HERMES_HOME to the parent's computed profile home (via `get_hermes_home()`)
3. **Context-local override** (`set_hermes_home_override` / `_HERMES_HOME_OVERRIDE` ContextVar) enables single-process multi-profile serving (desktop TUI gateway)
4. **Intentional shared paths** are version-controlled repo dirs, not profile data
